# Examples

Worked examples showing `pyfli` end-to-end. Each notebook can be downloaded
and re-run directly — use the download link at the top of its rendered page.

Notebooks are listed explicitly below (not auto-globbed from `examples/`), so
a notebook only appears here once it's deliberately added. For a clean page
title, give the notebook a top-level `# Title` markdown cell as its first
cell; otherwise the raw filename is used as a fallback. Before adding a
notebook here, replace any hardcoded local file/folder paths in its cells
with the placeholder `<select file/folder path>`, so the published notebook
doesn't leak a contributor's machine paths.
