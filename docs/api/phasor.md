# Phasor Analysis

Continuous, discrete, gated, and truncated phasor transforms of periodic decays, phasor loci for multi-component mixtures, and lifetime extraction from phasor coordinates. Implements the framework described in Michalet, *AIP Advances* **11**, 035331 (2021) — see [Citing pyfli](../citing.md).
